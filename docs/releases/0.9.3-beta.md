## Brasshaven 0.9.3-beta

Minecraft 26.2 · Forge 65.1.0 · Java 25 — mets à jour le serveur **et** chaque joueur avec le même jar (le monde est conservé).

### Nouveau : le livre de recettes intégré
- **Panneau d'objets** à droite de tous les inventaires (table de craft, fours, coffres, machines, terminal, villageois, créatif) : recherche (sans accents, `@mod`, `#tag`), filtre « Brasshaven / Tout », pages. Touche **I** pour l'afficher ou le masquer.
- **R** sur un objet : ses recettes. **U** : ses utilisations. Un onglet par type (craft, fours, tailleur de pierre, forge, établi à ciseler…), ingrédients alternatifs qui défilent, clic sur un ingrédient pour suivre la chaîne, retour arrière, bouton vers la page du Manuel.
- **Bouton « + »** : remplit la grille de craft avec tes objets (Maj + clic : le plus possible). C'est le serveur qui déplace les objets, comme le livre de recettes de Minecraft : aucune duplication possible. Les ingrédients manquants sont en rouge.
- Toutes les recettes du serveur, datapacks compris. S'il y a le vrai JEI, le livre s'efface (option pour garder les deux).

### Multijoueur
- **Taille des compagnies réglable jusqu'à 100** (`company.maxSize` dans `brasshaven-common.toml`, 8 par défaut). Avec une grande guilde, le HUD des compagnons montre les plus proches et « +N ».
